# Code of Conduct

SandboxStudio adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. Everyone taking part in the project's issues, pull
requests and discussions is expected to follow it.

In short: be welcoming and respectful, assume good intent, give and accept
constructive feedback, and focus on what is best for the project and its users.
Harassment, personal attacks and discriminatory language are not tolerated.

## Reporting

Report unacceptable behavior privately to the maintainer through a
[private security advisory](https://github.com/PAumedes/SandboxStudio/security/advisories/new)
(choose it even though the report is not about security) or by contacting
[@PAumedes](https://github.com/PAumedes) on GitHub. Reports are handled
confidentially, and the maintainer will act as described in the Covenant's
enforcement guidelines.
